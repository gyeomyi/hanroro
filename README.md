# 한로로 HANRORO — 팬사이트

싱어송라이터 **한로로**의 비공식 팬사이트. 빌드 도구 없는 정적 HTML/CSS/JS에
방명록만 Supabase로 붙였습니다.

> 컨셉은 "쓰는 사람". 한로로는 가사보다 산문을 먼저 쓰는 국문학도이고,
> 3집 〈자몽살구클럽〉은 동명 소설과 세계관을 공유합니다.
> 그래서 이 사이트는 가수 팬페이지가 아니라 **한 권의 책**으로 설계했습니다.

## 페이지

| `album-youandi.html` | 9th 디지털 싱글 〈너와 나〉 (2026.07.09, 폼폼푸린 컬래버) |

| `album-single.html` | 데뷔 싱글 〈입춘〉 (2022.03.14) |
| `guestbook.html` | 방명록 (작성 · 수정 · 삭제) |

## 실행

빌드가 없습니다. 정적 파일이라 그냥 열면 됩니다.

```bash
python -m http.server 8000
# http://localhost:8000
```

`index.html`을 더블클릭해도 동작하지만, 로컬 서버로 여는 쪽을 권합니다.

## 구조

```
css/style.css    메인·방명록 (밤/낮 2테마)
css/album.css    앨범 페이지 전용 — 앨범마다 다른 세계
js/theme.js      테마 전환 (localStorage)
js/guestbook.js  방명록 로직 (Supabase)
js/likes.js      앨범 좋아요 버튼
img/             모든 이미지. 표지는 cover-<앨범키>.jpg
```

### 두 개의 디자인 시스템

**메인·방명록** — 밤/낮 두 테마. 색은 전부 CSS 변수이고 두 테마가 같은 변수 집합을
정의합니다. 팔레트 근거는 데뷔곡 '입춘' — 아직 어두운데 봄이라 부르는 절기.
먹밤 바탕 위로 자몽·살구의 여명이 트는 배색입니다.

**앨범 페이지** — 메인의 셸(헤더·밴드·푸터)을 쓰지 않습니다. `css/album.css`가
레이아웃과 색을 전부 새로 정의하고, `<html data-album="...">` 하나로 전환됩니다.
**색은 전부 실제 표지 이미지에서 뽑았습니다.**

| | 앨범 | 세계 |
|---|------|------|
| `ep1` | 이상비행 | 검정 위 전기 파랑 |
| `ep2` | 집 | 검정 위 붉은 화염 |
| `ep3` | 자몽살구클럽 | 흰 종이에 색연필 (밝음) |
| `single` | 입춘 | 역광 바다의 푸른 새벽 |
| `youandi` | 너와 나 | 하늘색과 남색 선 (밝음) |

밤/낮 토글은 앨범 페이지에 없습니다. 그 표지의 세계 하나만 입습니다.

### 접근성

- 두 테마 · 다섯 앨범 세계 **전부 WCAG AA(4.5:1) 확인**
- `prefers-reduced-motion`에서 애니메이션 · 스크롤 효과 정지
- `:focus-visible` 아웃라인 유지

## 방명록

Supabase(PostgreSQL + REST). 로그인 없이 이름·내용·비밀번호로 글을 남기고,
그 비밀번호로만 수정·삭제할 수 있습니다.

- 테이블 조작은 전부 **RPC 함수**(`sign_guestbook` / `edit_guestbook` / `remove_guestbook`)를 거칩니다.
  RLS 정책상 클라이언트의 직접 INSERT/UPDATE/DELETE는 막혀 있습니다
- 비밀번호는 pgcrypto **bcrypt(cost 10)** 해시로만 저장하고, 해시 컬럼은
  컬럼 단위 권한으로 REST에서 읽을 수 없게 막아뒀습니다
- `js/guestbook.js`의 anon 키는 **공개용**입니다. 노출을 전제로 설계된 키이고
  실제 방어는 RLS와 컬럼 권한이 합니다
- 모든 사용자 입력은 `escapeHtml()`로 이스케이프합니다
- 길이·빈값 검증은 브라우저가 아니라 **서버(RPC)에서** 합니다. 비밀번호 실패가
  글 하나당 5분에 10회를 넘으면 잠깁니다
- 외부 CDN 스크립트는 버전을 고정하고 **SRI 해시**로 무결성을 검증합니다

## 앨범 좋아요

앨범 페이지마다 하트 버튼이 하나 있습니다. 로그인 없이 누를 수 있고, 다시 누르면 취소됩니다.
수는 Supabase에 앨범별로 하나씩 쌓입니다(`album_like` 테이블 + `like_album` RPC).

중복 방지는 브라우저 `localStorage`로만 합니다. 서버는 누가 눌렀는지 구분하지 않으니
정확한 집계가 아니라 **분위기용 숫자**로 봐주세요.
